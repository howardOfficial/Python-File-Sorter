# Скрипт для сортировки файлов

Простой скрипт на Python, который автоматически переименовывает файлы (добавляет дату) и раскладывает их по папкам в зависимости от расширения.
Стек: Python, os, shutil, datetime.

Как запустить:

Запустите скрипт: python file_sorter.py
Введите путь к папке, которую нужно отсортировать (например, C:/Downloads).
Скрипт создаст папки по расширениям и переместит туда файлы.
